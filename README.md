# Ecommerce Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing retail sales data to understand sales performance, customer purchasing behavior, product performance, and regional sales distribution.

The project involves data cleaning, data preprocessing, data transformation, and exploratory data analysis to generate meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall retail sales performance.
- Identify top-performing and low-performing products.
- Compare sales performance across different regions and states.
- Understand customer purchasing behavior.
- Analyze monthly and yearly sales trends.
- Evaluate the impact of discounts on sales.
- Identify product categories with higher sales and stock levels.

## 📂 Dataset Description

The dataset contains retail sales transaction details along with product, store, and customer information.

### Dataset Attributes

| Column Name | Description |
|---|---|
| Sales_ID | Unique sales transaction ID |
| Order_Date | Date of purchase |
| Customer_ID | Unique customer ID |
| Product_ID | Unique product ID |
| Store_ID | Store identification number |
| Region | Sales region |
| Quantity | Number of products purchased |
| Unit_Price | Price per unit |
| Discount | Discount applied |
| Payment_Type | Mode of payment |
| Total_Amount | Total transaction amount |
| Product_Name | Name of the product |
| Category | Product category |
| State_Name | State where the sale occurred |
| City | City where the sale occurred |
| Age | Customer age |
| Gender | Customer gender |

## 🔍 Data Cleaning & Preprocessing

The following data cleaning activities were performed:

1. Identified missing values in important columns.
2. Handled missing values using appropriate imputation techniques.
3. Used lookup functions to retrieve product names and state names.
4. Checked data consistency and accuracy.
5. Verified calculated sales amounts.
6. Organized and prepared the dataset for analysis.

## 📊 Exploratory Data Analysis

The following analyses were performed:

### 1. Sales Analysis
- Total sales revenue analysis.
- Monthly sales performance.
- Yearly sales comparison.
- Regional sales comparison.
- State-wise sales performance.

### 2. Product Analysis
- Category-wise sales performance.
- Top-selling products.
- Low-performing products.
- Product stock distribution.

### 3. Customer Analysis
- Gender-wise customer distribution.
- Age-wise customer analysis.
- Customer purchasing behavior.
- Average customer spending.

### 4. Discount Analysis
- Discount-wise sales performance.
- Average discount analysis.
- Comparison of sales across regions.

### 5. Payment Analysis
- Payment method distribution.
- Credit card, debit card, COD, and PayPal transaction analysis.

## 📈 Key Business Insights

The analysis helps identify:

- Best-performing regions and states.
- High-revenue product categories.
- Monthly and yearly sales trends.
- Customer purchasing patterns.
- Popular payment methods.
- Product categories requiring better stock management.
- Opportunities to improve sales through discount strategies.

## 💡 Business Recommendations

- Focus on high-performing products and categories to increase revenue.
- Improve marketing strategies in low-performing regions.
- Monitor monthly sales trends to plan inventory effectively.
- Optimize discount strategies to improve profitability.
- Maintain sufficient stock for high-demand products.
- Develop customer-focused marketing strategies based on purchasing behavior.
